# 人设卡（人格提示词）

每个角色一个 Markdown 文件，**文件名 = 角色名**（不含扩展名，中英文均可）。
例：`roles/小鲸鱼.md`。

用法：`/qq 人设 小鲸鱼` 切换；`/qq 人设 无` 清空；`/qq 人设` 查看全部。

---

## 一、人格卡只写「人设」，不写「怎么干活」

提示词分两层，这个划分从 qq-bridge 原样搬过来：

| 层 | 放在哪 | 管什么 |
| --- | --- | --- |
| **人格提示词** | 本目录的 `roles/<角色名>.md` | **你是谁**：身份、性格、说话风格、梗、雷点、和其他人的关系 |
| **仿真协议** | `qbridge/prompt.py` 的 `PROTOCOL_PROMPT` | **怎么干活**：工具怎么调、怎么分条、怎么潜水/唤醒、怎么用表情包与记忆 |

**不要把工具用法写进人格卡。** 原因：

- 工具协议由插件统一维护，写进人格卡会出现两份互相打架的说明；
- 插件已经在**每一轮**的系统提示词里给出当前工具面与分条规则，重复写只会占预算；
- 表情包、记忆、看图、合并转发、引用规则等能力，协议里都有完整章节。

想改「怎么干活」请改 `qbridge/prompt.py`（改完重载插件即可生效）；
想改「你是谁」请改本目录的 md 文件（**下一条消息即生效**，不用重载）。

## 二、当前可用的人设卡

| 文件 | 说明 |
| --- | --- |
| `小鲸鱼.md` | DeepSeek 小鲸鱼 QQ 群友版：去 AI 味、群聊说话铁律、主体性、雷点 |
| `傲娇助手.md` | 轻量示例卡：傲娇、嘴硬心软、简短带小脾气 |

`小鲸鱼.md` 是原项目里打磨得最细的一张卡，建议先用它。它的取向是
「先像群友、像真人，再谈人设」——如果你想要一个规矩的客服型机器人，
这张卡会显得很不听话，换成自己的卡或清空人设即可。

## 三、写卡的注意点

- **只写人格与语气**，不写「必须调用 xx 工具」这类操作说明。
- 人设卡会整篇注入系统提示词，太长会挤占上下文。插件默认上限 6000 字符
  （配置项 `persona.maxInjectChars`），超长会被截断并在末尾标注。
- 卡片里的内容会被模型当成设定，不要写敏感信息（密钥、内部地址）。
- 想区分群聊/私聊语气，直接在卡里写明「私聊时……群聊时……」，协议不会覆盖人格层。

---

## 四、和原项目的差异

原项目的卡片里可以写「〔一代〕/〔二代〕」标题标记来区分两套工具协议，
桥接会只注入当前模式适用的小节。AstrBot 版只有一套工具协议，**这个标记机制没有移植**，
卡片里若保留了这类小节，会整篇注入。已有卡片建议把这类小节删掉。
